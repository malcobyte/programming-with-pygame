# Game Design Document: [Your Game's Title]

## The Pitch

One sentence, no "and": *"It's a game where you ___."*

If you need "and" to describe it, the idea is probably still two
ideas. Keep narrowing it until it's one.

## Core Loop

The one thing the player does, over and over, that makes this a game
and not a picture. (Example: "dodge falling rocks while collecting
gems.")

## Core Mechanics (Minimum Viable Version)
